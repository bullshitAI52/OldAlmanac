01 / 加载、编辑与导出

JSON 内的模板、CSS 和内嵌图片就是整个工作区。空库保持空库，加载失败显示错误并可重试，不会回填默认数据。左侧可搜索、新增、修改、删除模板；预设 ID 的日期规则复用 calendar-art.js 的元信息，不会据此自动生成模板。

修改只在当前页面生效。离开前请导出完整模板库，替换服务器上的 calendar-templates.json；再次进入或刷新会重新读取文件。浏览器不会自动覆盖服务器或磁盘文件。右上角“导出 JSON”直接导出完整模板库，不再提供单模板导出。

02 / 一个 JSON 的格式

使用 calendar-art v2，包含 canvas、css、assets、templates。设计画布为 1000 × 741。仍兼容读取 solar-term-art v1；不再自动补齐节气或节日。完整库导出包含所有图层、内嵌图片和主题 CSS。

03 / 占位文字

占位符 含义
{{name}} 通用模板名称，如白露、中秋节
{{termName}} / {{festivalName}} 名称兼容别名，均取当前模板名称；方便跨分类复用旧布局
{{day}} / {{dayPadded}} 日期数字：7 / 07
{{year}} / {{month}} 公历年 / 月
{{date}} 完整公历日期 YYYY-MM-DD

编辑器用示例日期排版，不验证此日期是否真的是该节日；导出保存原始占位文本，不保存预览替换值。字体与主题色仍只通过主题 CSS 管理。

自定义节日日期绑定

左侧选中节日后，右侧顶部直接显示日期绑定属性，可选择每年公历或农历月／日（二选一），修改即时生效，导出后保留；不必打开模板设置。新增模板与模板设置仍保留同一绑定入口。农历只匹配非闰月；公历2月29日只在闰年出现，农历不存在的三十日不触发。规则随 JSON 保存，改名或修改自定义 ID 不需要改日历 JS。预设 ID 继续由 lunar.js 判断，不能用固定日期覆盖。未绑定的自定义模板不自动触发。

同日先按原有预设优先级选择可用模板，再按 JSON 顺序尝试自定义绑定；都没有可见内容时保留日期数字。图层上移／下移按钮位于左侧图层标题栏，选中图层后使用小箭头。

白色文字、字号与纯白外描边

选中文字后，可勾选“白色文字 · 用于深色背景”，让字面固定为纯白色；取消后恢复设计器的 CSS 颜色和日历的日期主题色。选项逐图层保存到 JSON，日历、截图、打印均保留白字；与外描边独立，不改变图片去白规则。字体整体透明度仍由 CSS 控制。

新增“日期数字”默认纯白外描边 6px，已有图层保持原值。选中「模板名称」「日期数字」或竖排文字图层时，属性面板提供「设置全局」：把当前模板里这些图层的排版属性（字号、位置、描边、缩放、样式类、竖排、字间距、白色文字，不含文字内容）一次写到同一分类里所有已有内容且含对应图层的模板；节日只改节日，节气只改节气；竖排文字按图层顺序对应，可撤销。选框提供四角与四边中点共八个控制点。文字始终等比缩放，字号同步更新；图片锁定比例时等比缩放，解锁后可按方向调整宽高。可切换竖排并设置正负字间距，清空字间距恢复 CSS；设置随 JSON 保存。旧模板没有独立字号时仍按 CSS 和原缩放显示；清空字号输入可恢复 CSS。外描边宽度以设计像素为单位，0 为关闭；固定纯白色，先描边再填字，不挤占字形内部。描边宽度不随字号缩放而变化，日历中也保留白色。

04 / WebP 与图片适配

上传支持 PNG / JPG / WebP，原图上限 12 MB。图片优先编码为 WebP，最长边不超过 2048 px。超出 400 × 1024 字节 时先降低质量，仍超限则逐步缩小尺寸；加载 JSON 内嵌旧图时也遵循相同流程。保留透明度。不支持 WebP 编码的浏览器回退 PNG 并继续缩小尺寸，界面会标注实际格式。

400 KB 指图片文件的二进制大小；嵌入 JSON 使用 Base64，长度通常会增加约 1/3，因此整个 JSON 不受 400 KB 限制。图片属性显示处理前后大小。

  • 适应宽：按原图比例，宽度等于画布宽度，垂直居中。
  • 适应高：按原图比例，高度等于画布高度，水平居中。
  • 填满：等比覆盖整个画布，居中裁切溢出部分，不拉伸变形。
  • 拉伸：不保留原比例，铺满 1000 × 741 画布，不裁切图片，自动解除比例锁定。

这些按钮保存计算后的坐标与宽高，不会裁掉源文件；之后可继续自由拖动、缩放。图片属性还提供水平翻转、垂直翻转，只改变本图层显示方向，不改原图素材，写入 JSON，日历中同样生效；再点一次还原。

批量设置 · 按文件名快建模板

左侧「🖼 批量设置」可一次选择多张图片（≤50 张）。取文件名去掉扩展名后的部分，按当前模板库中的名称、ID、别名匹配（含自定义节日／节气），再补内置预设：先精确匹配，再按最长包含匹配。找不到的跳过，已有设计内容的模板也跳过、不覆盖；跳过或单张失败不会中断整批，后面的空白／未设计模板仍会覆盖填充。匹配成功的图片自动压缩为 WebP（≤400 KB）拉满画布放在最底层，并在上面生成两个文字图层：左下角「当前日期」只显示当天数字 {{day}}（字号 350、纯白外描边 10 px），右上角「模板名称」{{name}}（字号 85、细纯白外描边）。两者都按真实字形测量贴到 60 px 边距处，并写入居中基准，个位数与两位数的天都保持居中、不补零。颜色与字体仍由模板 CSS 控制，可随时在右侧属性面板调整或删除。整批操作为一个撤销步骤；跳过明细见浏览器控制台，生成后请导出 JSON 才会保存。

05 / 操作与文件保存

图层支持复制、删除、隐藏、锁定、上移下移；模板级新增、修改、删除也支持撤销。本版不保存或恢复浏览器草稿。未导出的修改离开后不会保留，请导出 JSON 并替换源文件。
